# PentaLab — Proyecto integrador de Ingeniería Web I

Tienda virtual de PentaLab, marca colombiana de camisetas oversize con estampas gráficas de inspiración japonesa.

## Estructura
- `index.html`: página única con HTML5 semántico (header, nav, main, section, article, aside, figure, footer).
- `css/styles.css`: estilos CSS3 con Grid, Flexbox, variables y Media Queries (1024 px, 800 px y 480 px).
- `js/main.js`: menú plegable, formulario de pedido con total en vivo y mensaje listo para enviar.
- `img/`: logo y estampas de los tres diseños.

## Cómo verlo
Abre `index.html` en el navegador. No necesita instalación.
